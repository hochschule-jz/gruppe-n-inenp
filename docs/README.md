# docs/

Cross-cutting project documentation and demo evidence.

**Plan phases:** 0 (contract), 5 (measurements), 8 (demo runbook + screenshots).

## Key artifacts
- `contract.md` — **the Phase 0 locked contract** (pin map, MQTT topic scheme, JSON message
  format, identity model). This is the single most important shared document: backend code
  depends on the exact message shape and topic, so it is frozen before any backend work.
- Measurements: load-profile → cloud-usage → projected OPEX tables (Phase 5).
- Screenshots of the live demo (Phase 8).
- Demo runbook (swap to backup board, etc.).
